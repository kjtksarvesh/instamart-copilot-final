# Publish this project to GitHub

1. Create an empty **public** repository on GitHub (do not add a README, licence or .gitignore there).
2. Open a terminal in this extracted project folder.
3. If the folder does not already contain `.git`, run:

   ```bash
   git init -b main
   git add .
   git commit -m "Complete Instamart customer intelligence capstone"
   git remote add origin https://github.com/<your-user>/<your-repository>.git
   git push -u origin main
   ```

4. Submit `https://github.com/<your-user>/<your-repository>/tree/main`.

The repository must be public and the submitted URL must point to `main`.
